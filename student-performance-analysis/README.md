
# Student Performance Analysis Using Python

## About the Project
This beginner Python project analyses student performance using study hours and exam scores.

## Objectives
- Calculate the average student score.
- Identify the highest-scoring student.
- Find students scoring 70 or above.
- Compare study hours with exam scores.

## Technologies Used
- Python
- CSV data
- VS Code

## Dataset
The sample dataset contains six students, their study hours, and their scores.

## Key Findings
- Total students: 6
- Average score: 70.33
- Highest score: 95
- Top student: Anu

## Skills Demonstrated
- Reading CSV files with Python
- Data processing
- Calculating statistics
- Using loops and conditional statements

## Future Improvements
- Add charts to visualise student performance.
